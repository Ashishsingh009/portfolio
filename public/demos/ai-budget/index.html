On-device AI budget

PMs pick Gemma or Gemini Nano without a RAM or thermal budget. This calculator uses a simple working set model: RAM ≈ 1.6 × weights + KV, tokens/min from a published-style decode curve, thermal as a qualitative band. Numbers are estimates calibrated to public model cards + one emulator-class run (Pixel 8 profile in Android Emulator, API 35) — not a lab with 20 phones. Do not treat them as SLAs.
